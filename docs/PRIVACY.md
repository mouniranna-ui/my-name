## Scope

This policy describes the current TSBECM 202 skills-only package, its supporting files and the project's public GitHub support channel. The package provides instructions and CAD-generation code that run in the AI host or local environment selected by the user. It has no publisher-operated drawing-processing server, separate account system or external storage service.

## Drawing files and conversations

The publisher does not maintain external storage for users' private drawings, conversations or generated CAD files. Installing or invoking the package does not grant the publisher access to a user's private ChatGPT, Codex or Gemini conversations or attachments. The package contains no publisher telemetry or analytics endpoint, advertising integration, payment system or separate user database.

Drawing images, prompts, temporary working files, DXF files, PDFs and verification notes are processed or stored in the selected host's environment or on the user's computer. **No external publisher storage does not mean that the host stores nothing.** The host's settings and policies determine its own processing, storage, retention, sharing and model-training practices.

## Where information goes

| Activity | Recipient or location |
| --- | --- |
| Download the project, plugin or knowledge file | GitHub handles the download request |
| Attach drawings or write prompts in an AI product | The selected AI host receives that content |
| Run the CAD helpers | The selected host's execution environment or the user's local computer |
| Install Python dependencies, when permitted | The configured package source receives the dependency-download request |
| Save or download generated files | The host's supported file storage or the user's chosen local destination |
| Submit a support issue | The project's public GitHub issue tracker |

There is no built-in transfer of private drawing files to a TSBECM 202 server. Separate actions a user requests from an AI host or another integration are governed by that service and the permissions the user grants.

## Public support information

Support is provided through [GitHub issues](https://github.com/mouniranna-ui/my-name/issues). If you post an issue or comment, its contents and public GitHub account information are visible to the publisher and other visitors. Provide only the minimum non-confidential information needed to explain a problem. Use synthetic examples; do not post private drawings, customer details, credentials or other sensitive information.

The publisher has confirmed that there is no separate external storage for user data. GitHub hosts the issue history under its own policies. This policy does not promise that closing an issue deletes its contents, or that deletion removes copies held by third parties.

## Retention and deletion

TSBECM 202 does not operate a separate retention system for private drawings or chat files. Manage or delete those files through the AI host or the local environment where they were created. The publisher cannot delete data held in your host account.

For information voluntarily posted in this project's issue tracker, use the available GitHub controls or contact the maintainer through the relevant issue. Do not include additional sensitive data in a removal request. GitHub controls platform-level retention and deletion; no separate deletion deadline is promised here.

## Other services and contact

Review the policies of the services you choose, including [OpenAI's Privacy Policy](https://openai.com/policies/privacy-policy/) and [GitHub's General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Their policies are separate from this project's practices.

For questions about this package's data handling, follow the [support page](SUPPORT.md). This policy covers the current skills-only implementation; it does not describe an unbuilt hosted service or certify a public directory listing. See [publication status](PLUGIN_PUBLICATION.md).
